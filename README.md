# FH6AHK
Forza Horizon 6 AFK Farming
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Erstellt by Rndl :)
Mit F10 kannst du Starten / F11 wird das ganze Stoppen und AHK schließen danach musst du das Skript neu starten.
Sollten probleme auftauchen gerne im DC melden :) - spontaneboost -
!Änder auf keinen fall irgendwelche Timings Werte oder Namen hier das macht möglicherweiße das ganze skript kaputt!
Wenns garnicht geht musst du notfalls folgendes machen:
                                                        - Screenshots von den Menüpunkten selbst machen (Online, Rivalen, Horizon Rivalen, Streckenrennen, R-Klassen Tag, Rivalen wechseln,
                                                          Rivalen-Event starten, 2 Runde und von dem Navi unten das AutoDrive:Ein)
                                                          Macht die Screenshots so wie ich sonst könnte es nicht gehen Renamen nicht vergessen.
                                                        - Packt jetzt die PNG dateien in den gleichen Ordner mit den richtigen Namen.
                                                        - Sollte gehen sonst = Zeile 5!
Achtet auf die Dateinamen.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Du brauchst zuerstmal Autohotkey ohne den läuft garnix,                  ---> https://www.autohotkey.com/download/ahk-v2.exe
und Meine Skriptfile hier                                                ---> https://github.com/Helloworldsads/FH6AHK
Dann den Autohotkey erst installieren.
Dann meine Skriptfile bei dir Entpacken, einfach irgendwo oder direkt in Dokumente ziehen und den alten Ordner ersetzen wenn vorhanden. 
Eigentlich brauchst du die Readme nicht mehr lesen nur noch mein Skript Named "Starten hier" starten.
Ihr solltet also jetzt einen Tooltip sehen, Zuerst jedoch Ingame sein vor dem aktivieren.
Vorher Anna starten dann erst F10 und mit OK entspannt das Fenster bestätigen den Rest macht AHK jetzt im loop alleine ohne Bugs oder Fehler. 
Wenn doch sollte alles erklärt in der jeweiligen Meldung sein.
 
Viel Spaß!
